# Mobile Layouts

## Global mobile principles

- 1 hand use first
- thumb-zone primary actions
- high contrast dark mode
- scan-first for warehouse
- route-first for driver
- offline state always visible

## Admin APK layouts

### Home
- KPI carousel
- urgent alerts
- orders today
- live map mini
- quick actions

### Orders
- segmented status tabs
- compact order cards
- detail bottom sheet
- assign / approve actions

### Chat
- room list
- unread badges
- quick reply composer

### Reports
- prebuilt report cards
- export action sheet

## Warehouse APK layouts

### Dashboard
- scan CTA
- pending pick orders
- stock alerts
- attendance shortcut

### Scan
- full-screen scanner
- result sheet
- medicine + batch + expiry + location

### Pick order detail
- route by zone/rack/shelf/bin
- FEFO batch highlight
- confirm pick button
- exception report sheet

### Inventory count
- bin context header
- counted qty stepper
- variance badge
- sync state chip

## Driver APK layouts

### Dashboard
- today's deliveries
- next route
- check-in status
- connection/sync chip

### Delivery detail
- customer/pharmacy info
- order lines summary
- call/chat actions
- status stepper
- proof of delivery upload

### Live map
- route polyline
- current position
- destination info card
- arrive / delivered CTA

## Attendance mobile pattern

- geofence status pill
- selfie capture card
- check-in/out button
- timestamp + location evidence

## Offline UX

- yellow banner: queued changes
- red banner: sync failed
- green chip: synced
- queue detail drawer for admin/warehouse/driver
